# 苍穹防线 · 在线可玩版

**直接开玩：<https://leisurely94.github.io/sky-defense/>**

纵向飞行射击小游戏，单文件网页游戏，不需要安装或服务器，电脑浏览器打开即玩。

## 玩法与模式

- 经典模式：零件升级 + 永久金币，逐关推进
- Rogue 模式：每关结束后 5 张卡自选 2 张，死亡或重开则本局清空
- 故事模式：灯塔协议，10 章剧情教程
- 难度：普通 / 简单 / 困难 / 地狱（击破 30 关解锁）

## 文件说明

| 文件 | 用途 |

| `.nojekyll` | 让 GitHub Pages 不做 Jekyll 处理 |
| `README.md` | 本说明 |

## 存档说明

进度保存在浏览器 `localStorage`，按浏览器 + 网址隔离：

- 同一浏览器、同一网址刷新或重进，进度保留。
- 换浏览器、换网址、清理浏览器数据或使用无痕模式，进度不会跟过去。

## 分享给朋友

把 <https://leisurely94.github.io/sky-defense/> 发给对方，用浏览器打开即可，不需要 GitHub 账号。

## 后续更新

把新的 `index.html` 覆盖到仓库根目录（Add file → Upload files → 提交）后，Pages 会自动重新构建，地址不变；通常 1 分钟内生效。

## 兼容性

推荐桌面版 Chrome / Edge / Firefox 最新版本，游戏使用 960×600 逻辑画布并自动缩放适配窗口。
